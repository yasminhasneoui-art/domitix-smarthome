# domitix-smarthome

Domitix Smart Home is an IoT-based smart home system designed to control and monitor home devices remotely.  
The project focuses on automation, security, and energy efficiency.

## Features

-  Remote control of home devices (lights, fans, etc.)
-  Environmental monitoring (temperature, humidity)
-  Simple interface for user interaction
-  Basic security and access control
-  Expandable IoT architecture

##  Technologies Used

- C / C++
- Embedded Systems
- STM32
- Communication protocol WiFi
